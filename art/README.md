# 自訂角色圖

把圖片放進這個資料夾，遊戲載入時會自動使用，**全班都看得到**。
支援 `.png` / `.webp` / `.jpg`（優先順序如此），檔名必須完全一致：

| 檔名 | 對應角色 |
|---|---|
| `bg.png` | 戰鬥背景（建議 1000×560） |
| `hero_Blaze.png` | 我方・烈火 |
| `hero_Zephyr.png` | 我方・疾風 |
| `hero_Aegis.png` | 我方・岩盾 |
| `hero_Raiden.png` | 我方・雷神 |
| `enemy_0.png` | 敵方・下忍 ZAKO |
| `enemy_1.png` | 敵方・時態上忍 |
| `enemy_2.png` | 敵方・被動語態獸 |
| `enemy_3.png` | 敵方・條件句妖獸 |
| `enemy_4.png` | 敵方・片語動詞蟲群 |
| `enemy_5.png` | 敵方・最終魔神 GRAMMAROS |

**角色圖建議**：去背 PNG，人物站在圖片底部（腳貼齊下緣），高比寬長。
沒有放的檔案會自動使用內建的原創忍者圖，不會出錯。

放好後執行：

    cd ~/pet-game && git add -A && git commit -m "更新角色圖" && git push

約一分鐘後線上就會更新，網址與 QR code 不變。

> 只想在自己這台電腦上換圖、不發布給學生的話，
> 用遊戲標題畫面的「🖼 換角色圖」按鈕即可（存在瀏覽器，不會上傳）。

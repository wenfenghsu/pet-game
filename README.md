# PET 英文特訓 ROBOT WARS

劍橋 PET (B1) 程度的英文文法闖關遊戲，單一 HTML 檔、完全自包含。

**遊玩網址：** https://wenfenghsu.github.io/pet-game/

## 玩法
答對題目就開火攻擊敵機，答錯或超時遭到反擊。連續答對累積 COMBO 提升傷害，
擊破 5 台敵機後挑戰最終魔神。結束後提供文法弱點分析與錯題檢討。

## 內容
- 四台可選機體（超級系／真實系／支援系／平衡系），各有不同數值與特殊能力
- 題庫 2,300+ 題，由 183 個已驗證句型搭配詞彙插槽產生，每次開啟組合不同
- 涵蓋時態、情態動詞、條件句、被動語態、關係子句、轉述句、動名詞與不定詞、
  比較與程度、片語動詞與介系詞、數量詞與冠詞、用字搭配
- 結算提供 S–D 評等、各文法類別正確率、針對弱項的加強建議、完整錯題清單
- BGM 與音效由 WebAudio 即時合成，無外部檔案

## 技術
純前端單檔，無外部相依。美術為內嵌 SVG，支援手機與桌機。
